# VPN Deal Compare

Live site: https://taurus583.github.io/Vpn-comparison-site/

## How to update
Edit only `config.js`:
- `paypalEmail` — the PayPal account that receives payments
- `guidePrice` — price of the Premium Guide
- `affiliateLinks` — paste your affiliate links here

Save (commit) and the live site updates in about 1 minute.
